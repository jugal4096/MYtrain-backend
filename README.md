# 🚆 Indian Railway API

A Node.js and Express REST API that provides railway-related information for personal and experimental projects.

## ✨ API Capabilities
The original project describes endpoints for:
- Train information
- Train routes
- Trains on a given date
- Trains between stations

See the API documentation for endpoint details and request examples.

## 🧰 Tech Stack
- Node.js
- Express
- user-agents package

## 📚 API Documentation
[Open the Postman API documentation](https://documenter.getpostman.com/view/23795265/2s8YYHMiHF)

## 🚀 Getting Started
1. Install Node.js and npm.
2. Clone this repository and open the project directory.
3. Install dependencies with `npm install`.
4. Start the server using the start script defined in `package.json`, or the project's documented entry point.
5. Configure required environment variables locally; never commit API keys or secrets.
